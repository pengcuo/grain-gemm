# Thor single G256 INT8 GEMM: K1536, N1024

**Follow-up:** this initial candidate set omitted independent CuTe. See the [77-candidate CuTe-inclusive rerun](gemm_k1536_n1024_cute_emc2750.md). The reproduction script now includes CuTe; the measurements below retain the original 47-candidate run.

Measured 2026-10-21 19:46 CST. GPU frequency was reduced to **1.2 GHz (actual 1197 MHz)**; EMC remained fixed at **2750 MHz**. All six minimum/maximum/current readings matched these locks before and after samples.

One mathematical GEMM `A[M,1536] @ B[1536,1024]` is measured, with G256 INT8 inputs/weights, FP32 scales and BF16 output. There is no MoE routing, token replication, activation, quantization or combine in the timing. Input preparation is excluded. A is contiguous; B is the transpose of contiguous Linear weights `[1024,1536]`. Scales are contiguous `[M,6]` and `[6,1024]`.

## Results

Each warm value is an independent confirmation of the candidate chosen in a preceding warm screening, with repeated inputs and no cache flush. The cold column confirms the separately cold-selected candidate, clearing a 256 MB buffer outside each timed event. INT8 throughput is **TOPS**, using `2*M*N*K / time`; no sparsity factor is used.

| M | Auto warm µs (TOPS) | Warm-selected native µs (TOPS) | Cold-selected native µs (TOPS) |
| ---: | ---: | ---: | ---: |
| 1024 | 33.504 (96.14) | 33.088 (97.35) | 83.456 (38.60) |
| 2048 | 183.968 (35.02) | 49.792 (129.39) | 116.064 (55.51) |
| 4096 | 356.128 (36.18) | 83.872 (153.63) | 159.552 (80.76) |
| 8192 | 712.640 (36.16) | 170.080 (151.52) | 242.144 (106.42) |

The tested native configurations reach **153.63 TOPS** at M4096 and **151.52 TOPS** at M8192 under repeated-input timing; none of these tested shapes reaches 200 TOPS. This is specific to the tested implementation, shapes and clocks.

Public Auto uses CUTLASS #32 for M1024. The other three shapes have no measured dispatch entry and currently fall back to the portable Triton configuration (`32x64`, 4 warps, 2 stages, swizzle 8). That accounts for the large Auto/native gap. This benchmark does not update dispatch or production kernels.

## Candidate selection and validation

47 candidates were screened: public Auto, all 34 single-GEMM CUTLASS configurations, and all 12 native expert-GEMM configurations with **E=1**, all rows valid, swizzle 1 and raster 0. E=1 executes the same single mathematical GEMM with one weight matrix; it does not route tokens or batch different experts. `expert_*` below denotes this native entry point, not a multi-expert measurement.

Candidates were screened independently in cold and warm modes, three rounds per mode. Auto and both selected candidates were then confirmed independently over three rounds of three samples in each mode. Reported latency is the median of round medians. Each CUDA graph replay contains one GEMM. Selected candidates are fixed before confirmation; the table does not choose a new winner from confirmation samples.

| M | Cold selection | Warm selection | Auto backend |
| ---: | --- | --- | --- |
| 1024 | expert_36 | cutlass_32 | cutlass |
| 2048 | expert_34 | expert_36 | triton |
| 4096 | expert_46 | expert_36 | triton |
| 8192 | expert_43 | expert_36 | triton |

All 47 candidates for each shape passed sampled bit-exact BF16 checks against independent CPU INT32 per-group dot products with FP32 scaled accumulation, including zero and negative scale cases. Each check samples 27 elements across three rows and nine columns. Checks ran before and after graph capture; the cold-selected output was checked again after timing and every output element was finite. These are sampled numerical comparisons, not exhaustive comparisons.

Benchmark sources, native sources, wrapper/configuration files and binary fingerprints were unchanged during measurement. Maximum observed GPU temperature was 56.375 °C. The read-only guard pauses at 62 °C until 54 °C and aborts at 70 °C.

```bash
PYTHONPATH=src OMP_NUM_THREADS=4 python benchmarks/bench_gemm_rectangular.py \
  --rows 1024 2048 4096 8192 --n 1024 --k 1536 \
  --output /tmp/thor_gemm_k1536_n1024.json
```
